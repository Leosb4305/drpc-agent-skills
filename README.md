## 🛡️ Troubleshooting common issues

Most problems stem from network restrictions. If the tool fails to connect, follow these checks:

*   Check if your firewall blocks the tool. Allow the program through your Windows security settings.
*   Confirm your internet works.
*   Restart the program by closing it from the system tray and launching it again.
*   Ensure your DRPC API key is active if you have a custom account.

## 📖 Understanding technical terms

We use this tool to simplify how your computer talks to blockchains. 

*   Blockchain: A digital record of transactions.
*   RPC: A way for your computer to ask a blockchain to report its status.
*   Agent: The AI tool you use to write code.
*   MCP: A standard that helps AI tools talk to local software.

By using these terms, the program creates a common language between your AI and the blockchain networks. This setup improves the accuracy of the code your AI writes for web3 projects. Keep the program updated to ensure the best performance.
